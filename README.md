# Brazilian E-Commerce Sales Analytics Dashboard

## 📌 Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset (Olist) from 2016 to 2018 using SQL and Power BI. The objective is to transform raw e-commerce data into an interactive dashboard that provides insights into sales performance, customer behavior, payment methods, product categories, and delivery performance.

---

## 🎯 Project Objectives

- Analyze overall sales performance from 2016–2018.
- Monitor customer purchasing behavior and payment preferences.
- Evaluate delivery performance and customer satisfaction.
- Build an interactive dashboard to support business monitoring.

---

## 📂 Dataset

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

**Source:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

---

## 🛠 Tools

- SQL
- Power BI
- Power Query
- Excel

---

## 📋 Project Workflow

### 1. Data Validation (SQL)

Performed data quality checks before creating the dashboard by:

- Checking duplicate records
- Identifying missing values
- Investigating missing delivery dates by order status
- Verifying data consistency before visualization

### 2. Data Preparation

- Combined required datasets for analysis
- Prepared the dataset for Power BI

### 3. Dashboard Development (Power BI)

Built an interactive dashboard to analyze:

- Sales Performance
- Customer Behavior
- Product Categories
- Payment Methods
- Delivery Performance
- Geographic Sales Distribution

---

## 📊 Dashboard Pages

### Page 1 – Executive Summary

Provides an overview of business performance through KPIs, sales trends, payment methods, delivery performance, top product categories, and geographic sales distribution.

### Page 2 – Sales & Product Analysis

Provides a detailed analysis of sales performance, product categories, and sales trends.

### Page 3 – Customer & Delivery Analysis

Analyzes customer behavior, payment methods, review scores, and delivery performance.

---

## 💡 Key Insights

- Total sales reached **16.01M** across **99.44K orders** between 2016 and 2018.
- **Credit Card** was the most frequently used payment method, accounting for **73.9%** of all transactions.
- More than **90%** of orders were delivered on time.
- **Bed, Bath & Table** was the best-selling product category.
- **São Paulo** generated the highest total sales among all cities.
